# SkillSwap

SkillSwap is a Flutter application that helps students connect with peers to exchange skills.

## Features

* Create a skill profile
* List skills you can teach
* List skills you want to learn
* Discover matching learners and mentors
* Store profiles locally on the device

## Tech Stack

* Flutter
* Dart
* Provider
* SharedPreferences

## Project Status

Currently under development as part of the Android Club recruitment process.
